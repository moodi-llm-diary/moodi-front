회원가입 화면이 로그인 화면과 다른 테마를 사용할 수 있는 회귀를 방지한다. 기존 `App.tsx`는 두 인증 route에 동일한 시스템 테마를 적용하고 있었으므로 production code는 변경하지 않고, 로그인→회원가입 전환의 실제 테마 일치 회귀 테스트를 추가했다.
